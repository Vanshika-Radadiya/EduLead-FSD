# EduLead

EduLead is a Lead Management and Analytics System designed for education consultancies.

The system will help organizations manage admission enquiries coming from sources such as:

- Social Media
- Website
- Direct Enquiry
- Walk-ins
- Referrals
- Marketing Campaigns

## Tech Stack

### Frontend
React.js

### Backend
Django
Django REST Framework

### Database
MySQL

### Machine Learning
Python
Scikit-learn

## Main Users

- CMD / CMO / Admin
- Manager
- Counsellor
